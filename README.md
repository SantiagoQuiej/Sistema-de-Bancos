
# 🏦 Plataforma Bancaria

Aplicación web que simula una plataforma bancaria digital moderna.

---

## 🚀 Tecnologías

* ⚛️ React + Vite + TypeScript
* 🧭 React Router
* 🧠 Redux Toolkit 
* 🎨 Tailwind CSS
* 🧩 ShadCN UI
---

## 🔐 Funcionalidades

### 👤 Autenticación

* Registro de usuario
* Inicio de sesión
* Persistencia de sesión
* Rutas protegidas

---

### 💳 Gestión de Cuentas

* Crear cuenta bancaria
* Editar información
* Eliminar cuenta
* Visualización de saldo

---

### 💸 Deposito

* Validación de saldo
* Actualización de saldo
* Validación de datos de deposito


---

## 🥇 Fase 1 — Desarrollo Frontend

* Navegación funcional
* Datos simulados
* Estado global con Redux
* Responsive design

---

## 🎯 Objetivo del Proyecto

Este proyecto tiene fines educativos y de portafolio, simulando una aplicación bancaria real con arquitectura moderna.
